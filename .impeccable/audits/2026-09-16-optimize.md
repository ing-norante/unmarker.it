# Optimization: image workflow and startup

Scope: the homepage and image workflow served at `http://localhost:5173/`.
Validation used source inspection, production builds, and isolated unit checks. No local browser QA session was launched, per project instructions.

## Changes and evidence

| Bottleneck | Before | After |
| --- | --- | --- |
| Deliberate processing pauses | Three sequential 500 ms timers: 1,500 ms per successful run | Three zero-delay scheduling yields; no fixed presentation wait |
| Startup dependency on analytics | Hydration and client rendering awaited analytics initialization | Rendering starts independently; analytics failures are caught |

The processing regression check ran the existing orchestration with mocked image operations and a controlled clock. Before the fix it consumed 1,500 ms; afterward it completed within the check's 50 ms scheduling budget. This measures avoidable scheduling delay, not image-processing speed or end-to-end browser latency. Browser scheduling and background-tab throttling still apply.

Startup checks leave analytics initialization pending and confirm that both prerendered hydration and client rendering proceed. A separate check confirms that rejected initialization does not prevent rendering. These checks reproduced the startup block before the change.

Cancellation remains abortable between processing stages. Existing pixel-noise, JPEG encoding, localization, and accessibility checks also passed.

## Production bundle comparison

Bytes measured from production assets using Node's default gzip settings, consistently before and after:

| Chunk | Before gzip | After gzip |
| --- | ---: | ---: |
| Main entry | 81,706 B | 81,739 B |
| Image workflow | 44,567 B | 44,561 B |
| Analytics module | 78,689 B | 78,689 B |

This change removes waiting rather than reducing downloads. The small entry increase covers analytics error handling. The OpenCV worker remains deferred to image analysis.

## Validation

- 53 targeted unit checks passed across six files.
- Lint, TypeScript, client/SSR builds, prerendering, and localization verification passed.
- Impeccable detector on changed application files returned no findings.
- No Core Web Vitals or real-device timing claims were made.

## Human QA

On a production build, select and reprocess a small image; steps should advance as work finishes. Cancel during processing and confirm later stages stop. With analytics configured, throttle or block its module request and confirm that image selection still works. Repeat on a slower mobile device for actual responsiveness and processing timings.
