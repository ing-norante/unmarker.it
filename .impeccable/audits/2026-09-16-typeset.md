# Typography refinement

Scope: homepage, image workflow, shared messages, and panel typography. Source-based assessment and production CSS verification; browser QA remains with the project owner.

## Assessment and decisions

| Area | Evidence and decision |
| --- | --- |
| Authority and fit | `src/index.css` defines the established Geist Mono variable face and locale-specific Chinese system stack. Both remain authoritative for the Image Workbench. No additional family was needed. |
| Hierarchy | `ui/card.tsx` previously used weight 500 for panel titles. Titles now use 1.125rem / 700, rising to 1.25rem on wide screens; workflow titles use 1rem / 800. Compact captions and metadata retain separate smaller roles. |
| Scale | `.text-ui-body` previously resolved to 0.75rem against a 15px phone root: 11.25px. It now uses 1rem / 1.625. Ordinary panel, uploader, empty-state, and error descriptions also use a 1rem minimum. |
| Reading | `.text-reading` and shared descriptions cap prose at 65ch; narrow containers wrap naturally. Hero supporting text caps at 36ch. Headings use balanced wrapping; prose uses pretty wrapping. Chinese explanatory roles use 1.7 leading and a 36ic maximum. |
| Stress | The root uses 100% of the browser preference, or 106.25% at 1536px and wider. Existing container layouts, wordmark sizing, metadata wrapping, and expandable preview frames remain. Pipeline title/status rows can wrap when larger text needs room. Actual zoom and localization fit require human visual QA. |
| Delivery | The production build still emits one 23.12 kB Latin variable WOFF2 asset. `font-display: swap` and the existing system fallbacks remain. No new font requests or weights were added. Font-swap layout movement was not measured. |
| Numeric data | AI score and before/after values use tabular numerals, matching the quality control. The generated Tailwind rule sets `--tw-numeric-spacing: tabular-nums` and includes it in `font-variant-numeric`. |

## Mechanical scan

The type-scoped scan ran before and after editing. The source assessment identified undersized instructions and weak panel titles that the detector did not flag.

Remaining findings are explained by the existing design:

- Geist is flagged as an overused font; the confirmed identity uses Geist Mono and remains unchanged.
- The 5rem display size and 0.8rem compact button label are existing role-specific overrides.
- Chinese fluid endpoints at 6.5rem, 1.875rem, 1.25rem, and 2.25rem are locale-specific overrides documented in `DESIGN.md`, outside its baseline token list.

The changed title, body, and instruction roles are recorded in `DESIGN.md` and its sidecar.

## Verification

- 35 existing localization and accessibility checks passed.
- Lint, TypeScript, production client/SSR builds, prerendering, and localization verification passed.
- Production CSS contains the percentage root sizes, reading measures, Chinese line height, balanced heading wrapping, tabular numeral utility, and swap font loading.
- No browser QA session was launched. Source checks do not establish visual fit, font fallback metrics, or absence of layout shift.

Human review: compare both languages and themes at 320px, 390px, tablet width, and the desktop split; inspect long labels and metadata at 200% zoom and with a larger browser default font. Check loading and error states as well as completed results.
